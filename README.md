## Dataset

The notebook uses a **public CSV URL directly**, so `anime.csv` does not need to be downloaded or placed beside the notebook.

**Dataset repository:** https://github.com/meesvandongen/anime-dataset

**Direct CSV URL:** https://raw.githubusercontent.com/meesvandongen/anime-dataset/main/data/anime.csv

## Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

Start Jupyter:

```bash
jupyter notebook
```

Open:

```text
Anaya_AnimeAnalysis.ipynb
```

Then use:

**Kernel → Restart Kernel → Run All**

An internet connection is required because the notebook reads the CSV directly from the public URL.

## Important

You do **not** need:

```text
anime.csv
```

in your project folder.

The notebook itself contains the public dataset URL.
